# 📰 DailyBrief AI

> Personalized Indian Current Affairs & News Agent powered by GenAI.

🔗 **Live Demo:** [[YOUR_RENDER_URL_HERE](https://dailybrief-ai-lat4.onrender.com/)]

DailyBrief AI is an AI-powered news briefing application that collects
Indian news, groups related reports into real-world events, generates
concise AI summaries, ranks stories based on user preferences, and
supports conversational follow-up questions using fresh web search.

---

## ✨ Features

- 🇮🇳 Indian news across multiple categories
- 🧩 Groups related articles into a single real-world news event
- 🤖 AI-generated synthesized news summaries
- 🔑 Key facts for every story
- 💡 "Why It Matters" explanation
- 🎯 High / Medium / Low category priorities
- 🚨 "You Should Know" section for highly important events
- 🔗 Clickable original news sources
- 📅 Publication date and time
- 💬 Conversational follow-up questions
- 🔎 Fresh web search for follow-up questions
- 📱 Responsive product-style web interface
- 🔐 API keys stored securely using environment variables
