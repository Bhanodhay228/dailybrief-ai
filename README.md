# 📰 DailyBrief AI

> Personalized Indian Current Affairs & News Agent powered by GenAI.

🔗 **Live Demo:** https://dailybrief-ai-lat4.onrender.com/

DailyBrief AI is an AI-powered news briefing application that collects Indian news, groups related reports into real-world events, generates concise AI summaries, ranks stories based on user preferences, and supports conversational follow-up questions using fresh web search.

It also provides a separate **Government Exam Current Affairs** mode designed for competitive-exam aspirants.

---

## ✨ Features

- 🇮🇳 Indian news across multiple categories
- 🧩 Groups related articles into a single real-world news event
- 🤖 AI-generated synthesized news summaries
- 🔑 Key facts for every story
- 💡 "Why It Matters" explanation
- 🎯 High / Medium / Low category priorities
- 🚨 "You Should Know" section for highly important events
- 🔗 Clickable original news sources
- 📅 Publication date and time
- 💬 Conversational follow-up questions
- 🔎 Fresh web search for follow-up questions
- 🎯 Separate Government Exam Current Affairs mode
- 📚 Exam-focused current affairs for SSC, Banking, Railway, UPSC and State PSC
- 🏛️ Government schemes, appointments, awards, defence, economy, RBI, reports, science, space, international relations and more
- 📝 Exam facts and one-line revision points
- 🌙 Dark / Light mode
- ⚙️ Personalized category preferences
- 📱 Responsive product-style web interface
- 🔐 API keys stored securely using environment variables
